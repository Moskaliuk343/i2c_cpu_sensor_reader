# I²C CPU Sensor Reader

Курсовий проєкт мовою Rust для роботи з температурними сенсорами через інтерфейс I²C.

## Поточна версія

**v0.3.0 — віртуальний сенсор (Mock Mode)**

На цьому етапі програма підтримує:
- Імітацію температурного сенсора TMP102.
- Кодування та декодування температурних даних.
- Налаштування через командний рядок.
- Обробку помилок.
- Автоматичне тестування.
- Запуск на Windows, Linux та macOS у віртуальному режимі.

**Увага:** поточна версія не вимірює реальну температуру процесора. Підтримка фізичного I²C-сенсора запланована для наступних версій.

## Вимоги

- Rust та Cargo.
- Git для клонування репозиторію.

## Встановлення

```bash
git clone https://github.com/USERNAME/i2c_cpu_sensor_reader.git
cd i2c_cpu_sensor_reader
cargo build
```

Замініть `USERNAME` на ім'я власника репозиторію GitHub.

## Запуск

```bash
cargo run
```

Запуск із параметрами:

```bash
cargo run -- --count 5 --interval 2 --address 0x48
```

## Параметри

| Параметр | Опис |
|---|---|
| `--count N` | Кількість вимірювань (1–1000) |
| `--interval N` | Інтервал у секундах (1–60) |
| `--address HEX` | Адреса віртуального сенсора |
| `--help` | Довідка |
